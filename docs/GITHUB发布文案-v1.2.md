```markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版不新增功能，只做一件事：**把"绝不打错地方"这条底线真正做实**，并修掉音频与协议层的三个隐患。
单元测试 **56 → 82 条全部通过**。

## 🎁 本版修复

**1. 「测试识别」不再往外打字（重要）**
以前点「测试识别」验证凭据时，识别结果会被打进设置窗**背后的那个程序**，设置窗还会自己消失。
本版严格遵守承诺：**测试结果只显示在窗口里**，一个字都不会外打，窗口也不会再被收起。

**2. 松手后切窗口，也不会打错地方（重要）**
上一版只防住了"录音过程中"的切窗口。本版把**松手后等最终结果的那段空档**也补上了 ——
以前在这段时间切走窗口，迟到的补打甚至纠错退格会落到新窗口里，**删掉你正在编辑的内容**。
现在无论哪个阶段切走窗口，都会安全放弃本次输入并给出提示。

**3. 中途切走窗口的行为统一了**
以前：开着「边说话边打字」时切窗口 → 一个字不打；关着时 → **整段文字打进新窗口**（自相矛盾）。
现在统一为：中途切走就一律放弃自动输入（结果仍保留在设置窗的「最近识别」里）。

**4. 腾讯云 / 豆包：松手后立刻出字**
这两家会把「结束标记」和「最后一句文本」放在同一个数据包里，以前的解析会漏掉结束标记，
导致松手后界面还显示"录音中"、要白等满 8 秒。现在收到最后一包就立即收尾。

**5. 蓝牙耳机不再"慢放"**
用蓝牙耳机的免提/通话模式时（通常是 8kHz），音频以前不会被补采样，等于把声音慢放一倍发给识别服务
—— 结果基本是乱码。本版起按线性插值升采样到 16kHz，日志里会写明「线性插值升采样」。

**6. 其他**
修正「测试识别」界面计时与 5 秒上限的起跑线不一致；修正部分内部取值与注释不符的小问题。

## ⚠️ 升级与行为变化

直接用 `BBVoxi-1.2.exe` 覆盖旧版即可，**配置自动兼容，无需重填**。

唯一的行为变化：如果你平时**关掉了**「边说话边打字」，并且习惯在录音中途切换窗口 ——
本版起这种情况**不会再自动输入到新窗口**（这是为了不把你正在编辑的内容打乱）。

## 🚀 核心能力（延续）

- 按住快捷键说话，松开即输入到光标处；边说边出字，识别被修正时自动回退重打
- 不碰剪贴板（`SendInput` + `KEYEVENTF_UNICODE` 逐字符注入），你正在复制的内容不会被打断
- 三家流式 ASR 可切换：阿里云百炼（千问）/ 火山引擎（豆包）/ 腾讯云
- 托盘常驻、关窗即最小化；双击 exe 可唤起后台实例；开机自启可选
- 单文件 exe，免安装、无需运行库
