```markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版解决三件事：**快捷键不能自由组合**、**开机自启会弹窗**、以及一轮全量审查中
查出的 **31 处"出错却不吭声"的隐患**（会丢字、会卡死、会悄悄失败的那种）。
单元测试 **98 → 139 条全部通过**。

## 🎁 本版重点

**1. 快捷键真正实现"随便设"（核心）**

以前只有固定几种组合可用，现在：

- 修饰键 `Ctrl / Alt / Shift / Win` **任意 1~4 个搭配**，录制时**先松哪个键都不会丢**
- 主键覆盖**全部可录制按键**：字母、数字、`F1`~`F24`、空格、方向键、翻页键、符号键……
- **默认快捷键改为 `Ctrl + Win`**（左 Win、右 Win 都认）
- 老配置文件里的旧默认值会在启动时**自动升级**成 `Ctrl + Win`；你自定义过的组合**一律不动**
- 两条安全线（防止和系统打架）：**单个修饰键**（如只按 `Ctrl`）和**单个普通键**不会被设为快捷键

**2. 开机自启不再弹窗**

自启时带 `--autostart` 参数，**开机直接缩在托盘里，一个窗口都不弹**；
手动双击 exe 仍然照常打开设置界面 —— 两者靠"系统开机时长"区分，不会互相误判。
用旧版升级上来的，第一次开机就会被正确识别为自启，并自动把注册表项升级成新格式。

**3. 结果交付更可靠**

录音途中切走了窗口、或者字打不进去时：**一个字都不会打到别的地方**，
同时把完整结果放进剪贴板并弹出提示（按 `Ctrl+V` 即可粘贴）。
本版还修掉了一个"提示弹不出来"的缺陷 —— 以前这条提示可能被主窗口的隐藏指令盖掉，你什么也看不到。

## 🐞 本版修复（一轮全量代码审查 · 31 项）

**【严重】会丢字 / 卡死 / 界面卡住**

- **录音尾巴固定少最多 100 毫秒语音**：停止录音时，重采样器里还压着的样本被一起丢掉了。
  现在会把这些真实样本**补发**出去，并给采集线程 60 毫秒收工时间（消除补发没赶上就被丢的竞态）
- **拔掉麦克风后界面一直显示"录音中"**：现在会立刻停止并如实报「麦克风异常：具体原因」
- **网络半死时整个程序卡死**：Wi-Fi 掉线（没有 RST）时发送会永久挂住，松开快捷键也收不到，
  之后所有热键都失灵。现在所有发送与收尾步骤都有 **5 秒超时**，最坏 5 秒收场
- **收尾"边录边发"结束不了**：改为「先停麦克风 → 再收干残留 → 最后释放」
- **注入失败过之后，结果被静默丢弃**：收尾改成三态（成功 / 放弃 / 失败），
  后两种一律把结果放进剪贴板，绝不出现"两头都取不到"的情况
- **逐字注入只打进去一半时整段重粘 → 重复打字**：现在只补**没打进去的那一小段尾巴**

**【中等】数据与状态不一致**

- **用豆包服务商时，二遍识别会丢后半段 / 后半段重复**：服务端会改写、重排结果数组，
  原来按"数组下标"追踪必然错位。改成**整段快照 + 固定编号替换**：重复的挡掉、改写的整段覆盖
- **用腾讯云时看不到"边说边出字"的中间结果**：`slice_type = 0` 这种包以前被当成"忽略"，
  现在按中间结果正常显示
- **退格 / 回车 / Tab 在部分程序里失灵**：这三个键以前只发虚拟键码、不带扫描码，
  只认扫描码的程序（游戏、部分远程桌面）看不见。现在统一带**真实扫描码**
- **服务端推送异常时内存会被吃光**：改成 64 格有界通道，满了丢帧并记录日志，读取任务永远向前走
- **剪贴板清空失败会漏掉一块系统内存**；写入顺序也确保"先把新内容准备好、最后才清空"
- **服务端返回坏帧被悄悄吞掉**：现在记录帧长与特征字节，连续 5 帧解析失败就如实报错
- **手动双击 exe 被误判成"开机自启"**（窗口一个都不弹）：加了"系统开机 5 分钟内"这个条件区分
- **窗口最小化后从托盘打不开**：修正为「先解除最小化 → 再显示 → 延后一帧抢焦点」
- **抢前台经常失败**：显示与抢焦点不再同一帧下发
- **托盘图标创建失败就永久放弃**（再也看不到界面）：改为每 30 秒自动重试
- **写日志可能自己把自己锁死**：加了重入保护，**绝不自死锁**；滚动失败也不再静默
- **配置损坏时静默用默认值**：现在写日志；多实例并发保存不会互相覆盖

**【轻微】小问题一箩筐**

- 改键界面写着"支持 Esc"，实际上带组合键的 Esc 永远录不进去 → 已修（裸 Esc 取消录制，组合 Esc 正常录制）
- 单实例互斥量创建失败、界面创建失败等路径补齐日志留痕
- 打包脚本补了环境变量依赖声明；清理死代码并补齐 3 条新逻辑的回归测试

## ⚠️ 升级与行为变化

直接用 `BBVoxi-1.3.1.exe` 覆盖旧版即可，**配置自动兼容，无需重填**。

- **默认快捷键**变成 `Ctrl + Win`（老默认值会自动升级；你自定义过的不会被改）
- **开机自启现在是静默的**（不弹窗）；想开界面请双击 exe 或点托盘图标
- **升级后请重新勾选一次「开机自启」**：注册表里记的还是旧 exe 的路径

## ❗ 仍然存在的限制（说清楚，不夸大）

- 目标窗口以**管理员权限**运行时无法输入（Windows 系统限制），`Ctrl+V` 同样被拦 ——
  但**结果仍会复制到剪贴板**，粘到普通权限的窗口里就行
- **焦点不在任何输入框里**时，注入和粘贴都不会生效 —— 请打开「识别结果总留一份到剪贴板」，
  或去设置窗的「最近识别」里取
- 极少数程序会"**假装收下了**"我们的输入（报成功但字被丢弃）：Windows 没有通用接口能查证，
  建议打开「识别结果总留一份到剪贴板」兜住
- **同一个窗口里你自己挪了光标**再发生纠错退格时，可能删到非预期位置 ——
  光标位置只存在于目标程序内部，技术上无法检测（已知限制）
- 含 `Win` + 普通主键的组合会被系统抢先响应（截图、锁屏等）—— 这是 Windows 保留键的既定行为
- 剪贴板兜底只能保住**文本**：你原来复制的是图片或文件时无法还原（系统机制限制，日志会写明）

## 🚀 核心能力（延续）

- 按住快捷键说话，松开即输入到光标处；边说边出字，识别被修正时自动回退重打
- 默认不碰剪贴板（逐字注入），你正在复制的内容不会被打断
- 三家流式 ASR 可切换：阿里云百炼（千问）/ 火山引擎（豆包）/ 腾讯云
- 托盘常驻、关窗即最小化；双击 exe 可唤起后台实例；开机自启可选（静默）
- 单文件 exe，免安装、无需运行库
