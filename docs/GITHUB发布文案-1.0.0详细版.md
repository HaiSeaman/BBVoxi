## 正文（复制下面整块）

```markdown
**按住快捷键说话，松开，文字直接出现在光标处。**

BBVoxi 是一个常驻 Windows 系统托盘的语音输入法。它解决的是一个很具体的问题：**想说话出字，但不要多一个窗口、不要打断正在复制的内容、不要等松手才看到字。**

- 没有悬浮窗：识别结果直接进光标位置，像键盘打字一样
- 不碰剪贴板：你正在复制的东西不会被覆盖
- 边说边出字：识别被修正时自动回退重打，不会留下错误前缀
- 单文件免安装：约 8 MB，不需要 VC++ 运行库 / WebView2 / .NET

## 一、这一版能做什么

| 触发方式 | 行为 | 文字去向 |
|---|---|---|
| **按住快捷键**（默认 `Ctrl + 1`） | 按住期间录音，松开即结束并输入 | 直接进光标处 |
| **托盘 → 开始录音 / 停止录音** | 点一次开始，再点一次结束 | 直接进光标处 |
| **设置窗 → 测试识别（5 秒）** | 固定 5 秒自动结束，用来验证凭据与麦克风 | **只显示在窗口里，不外打** |

快捷键可改成任意 `Ctrl / Alt / Shift` + 字母、数字、`F1`~`F12` 或空格，**改完点保存立即生效**；按住时会拦截该组合键（不会触发浏览器切标签之类的系统快捷键）。

**三家服务商可切换，凭据用你自己的：**
- 阿里云百炼（通义千问，`qwen-audio-3.0-asr-flash-streaming`）
- 火山引擎（豆包，`volc.seedasr.sauc.duration`，支持高精度二遍识别）
- 腾讯云实时语音识别（`Hy-ASR-3.0-preview` / `16k_zh_en`）

接口地址已内置写死，你只需要填自己的 Key（腾讯云填 App ID / Secret ID / Secret Key 三元组）。

## 二、功能清单

- [x] 全局快捷键录音（默认 `Ctrl + 1`，可自定义，改完即生效）
- [x] 按住期间**吞掉组合键**，不向前台程序泄漏
- [x] **边说边出字**：中间结果实时写入光标处
- [x] **自动纠错**：识别修正时只回退被改动的字并重打（最长公共前缀差分）
- [x] 松手**收尾对账**：确保屏幕上的文字严格等于最终识别结果
- [x] 光标处注入走 `SendInput` + `KEYEVENTF_UNICODE`，**不使用剪贴板**
- [x] 注入前清理修饰键，避免自动纠错的退格被当成 `Ctrl+退格`（会删掉整个词）
- [x] 支持中文、生僻字与 emoji（UTF-16 代理对按字符处理）
- [x] 托盘三态图标（待机 / 录音中红点 / 出错橙点）+ 悬浮提示文字
- [x] **关窗即最小化到托盘**，不退出进程
- [x] 开机自启可选（注册表 `Run` 项，随时可关）
- [x] 深浅色主题自动跟随系统
- [x] 单文件 exe，静态链接，无运行时依赖

## 三、安装与使用（4 步）

1. 下载下方 `BBVoxi-1.0.0.exe`，放到任意目录（推荐 `%LOCALAPPDATA%\BBVoxi\`），双击运行；
2. 托盘出现图标，首次运行会自动弹出设置窗；
3. 选择服务商 → 填入**你自己的** API Key；
4. 点「测试识别（5 秒）」说一句话确认能出字 → 点「保存」。

之后在任意程序的光标处**按住快捷键说话，松开即输入**。

**卸载**：直接删除 exe 即可。用户数据（配置与日志）保留在 `%APPDATA%\BBVoxi\`，想彻底清理就删掉该目录。

## 五、这一版是怎么做出来的（七轮迭代）

1.0.0 不是一次写成的，而是七轮"发现问题 → 定位根因 → 修复 → 补回归测试"的结果。开发过程中真实解决过的问题：

| 轮次 | 问题 | 根因 |
|---|---|---|
| 2 | 点测试按钮**直接闪退**，没有任何提示 | release 用了 `panic = "abort"`，任何 panic 静默退出；深层原因是 `rustls` 0.23 缺少进程级加密后端（ring 未启用），首次 TLS 握手即 panic |
| 3 | 快捷键**完全按不动** | Windows 低级键盘钩子上报的是左右分开的虚拟键码，判定表漏了**左 Ctrl（0xA2）**，导致最常用的 `Ctrl+X` 从未生效 |
| 4 | 松开快捷键**不出字**，要等 55 秒才输出 | 会话循环把 `Cmd::Stop` 当无关指令忽略掉了——松手信号被自己吞了 |
| 6 | 打字**一卡一卡**（日志实证：10 秒录音里 9 秒在等待） | 注入前"等修饰键松开（最多 1.5 秒）"在按住说话时永远等不到，还把音频发送一起堵住了 |
| 7 | 长按时前台出现满屏 `111111` | 钩子把自己注入的修饰键 KEYUP 误当成"用户松开 Ctrl"，于是触发键不再被吞 |
| 7 | 收尾时可能**删掉已经打出来的字** | 最后一句未定稿时返回文本短于已注入文本，收尾对账反而退格删字 |
| 7 | 录音中出现**修饰键未恢复**导致的按键异常 | 修饰键重置事件未与文本同批注入 |

修复同时补齐了工程保障：panic 带文件行号写日志、会话逻辑 `catch_unwind` 包裹、修饰键判定收敛为单一事实来源、纯函数化后可单元测试。

## 七、隐私说明

- **不收集**：用户名、机器码、地理位置、输入法历史、使用统计
- **不上传**：除你录制的语音之外的任何东西
- **只发语音**：且只发给你在设置里选定的那家 ASR 服务商，松手即停
- **无遥测**：没有第三方统计 SDK
- **API Key 保存在本地**：`%APPDATA%\BBVoxi\config.json`（当前版本为明文存储，后续版本计划接入 Windows DPAPI 加密）

> 提示：如果你的用户目录参与网盘/OneDrive 同步，配置文件可能被同步到云端，介意的话请把该目录排除。

## 八、已知限制

- **仅 64 位 Windows**，不支持 Win7 / 32 位系统
- **仅中文识别**（1.0.0 不提供语言选项）
- **管理员权限的窗口无法输入**：目标程序以管理员运行时 `SendInput` 会被 Windows UIPI 机制拦住，程序会给出明确提示；请改用普通权限窗口
- **腾讯引擎单次上限 60 秒**（服务端限制，千问与豆包无此时限）
- **实时输入依赖"文本记账"**：若目标程序对输入做自动改写（如编辑器自动补全），差分可能与实际不同步，可在设置里关闭实时输入规避
- **托盘"开始录音"需手动停止**（没有静音自动断句）
- **内存占用**：常驻约 114 MB，设置窗可见时约 170 MB（egui + 中文字体基线开销）
