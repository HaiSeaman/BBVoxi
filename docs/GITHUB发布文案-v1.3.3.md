````markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版做两件事：**把设置界面重排到一屏看全**（并让浅色主题真正看得清），

## 🎨 界面重排（方案 C）

| 指标 | 上一版 | 本版 |
|---|---|---|
| 内容总高 | 1274px | **692px**（省 46%） |
| 卡片数 | 5 张 | **2 张** |
| 「最近识别」位置 | 599px 处（768 高的笔记本上**完全看不见**） | **98px**（第一眼就看到实时文字） |
| 900 高的窗口 | 还要滚 612px | **一屏看全** |

- 「最近识别」提到品牌栏正下方 —— 测试录音时不用滚动就能看到实时文字
  （旧版把它排在三张配置卡之后，恰好在最需要它的笔记本上失效）
- 服务商 / 凭据 / 快捷键 / 识别选项 / 通用 **合并成一张设置卡**：字段与标签同排，取消「高级」折叠
- **所有说明文字收进悬停气泡**（右侧小 `i` 图标）：一句话都没删，但页面不再被说明小字占掉 30% 高度
- 品牌栏压到 42px；底部按钮收窄；卡片加柔和投影、切换加 0.12 秒过渡、滚动条平时隐藏

**浅色主题对比度按 WCAG 公式修到全部达标**（这是实测数字，不是估的）：

- 成功绿 3.37 → **6.20**，警告橙 3.38 → **6.39**，危险红 → **6.46**
- 右上角状态胶囊上的小字 2.88 → **5.0+**
- 「自动添加标点 / 口语顺滑」被禁用时 1.99（等于隐形）→ **5.5**

另外：**状态消息 10 秒后自动消失**（旧版一条「已保存」会永远挂在界面上）；
**点 ✕ 关窗时若有未保存的改动会先问一句**（保存并关闭 / 不保存 / 取消）；
字号收敛到 4 档语义名；把"只比红通道差值"的**假对比度单测**换成真 WCAG 公式——它一次抓出 10 处不达标。

## 🔧 7 条硬伤修复

**直接丢字 / 重复打字（4 条）**

1. **会话中途失败不再丢最终结果**：麦克风异常 / 网络超时以前会直接放弃收尾 ——
   服务端其实已经把这句话定稿了却没人去取，「最近识别」停在上一次。现在失败与正常路径
   **共用同一套收尾**（发结束帧 → 等最终结果 → 关连接），结果照样交付（能打字就打字、
   否则进剪贴板）并说清失败原因；链路已断时等待窗口从 8 秒收到 2 秒，不干等
2. **后台识别线程起不来时界面看得见**：以前只写日志 —— 按快捷键毫无反应，而托盘和设置窗一切正常
3. **生僻字 / emoji 的退格数按 UTF-16 编码单元算**：按"字符"算会少退一位，
   在目标程序里留下半个代理对的乱码（顺带修掉 `\r` 被算进退格数）
4. **注入部分失败不再整段重粘**：`SendInput` 分批提交时被拒，以前会把**整段**再粘一遍
   → 目标程序里出现两份同样的字。现在只补没进去的尾巴

**判断错误 / 静默失败（3 条）**

5. **陈旧错误码不再误判**：`SendInput` 成功时不写错误码，旧版照读，于是几百毫秒前留下的
   "拒绝访问(5)"会把"部分成功"误判成被系统拦下、白跳过粘贴兜底
6. **注入搬出键盘钩子回调**：回调里直接注入，一旦被卡过系统 300ms 超时，Windows 会**静默摘掉钩子**
   （快捷键全废、Win 键乱弹、日志无痕）。现在回调只丢一个任务进通道，注入由专用线程做
7. **全局钩子装不上要报出来**：以前只写日志、程序"一切正常"，实际一个键都没接管

## ⚠️ 升级与行为变化

退出正在运行的旧实例（托盘右键 → 退出），用 `BBVoxi-1.3.3.exe` 覆盖即可。
**本版没有配置迁移**（配置版本仍为 2），服务商、凭据、快捷键、识别选项、开机自启全部原样保留。

界面会变成新布局（2 张卡 + 悬停说明气泡）；一时找不到某项设置时，把鼠标停到右侧的小 `i` 上看说明。

## ❗ 仍然存在的限制（说清楚，不夸大）

- 目标窗口以**管理员权限**运行时无法输入（Windows 系统限制），`Ctrl+V` 同样被拦——
  但结果仍会留在剪贴板，粘到普通权限的窗口里就行
- 极少数程序会"**假装收下了**"我们的输入：Windows 没有通用接口能查证，所以不做"检测到没进去就
  自动再粘一次"——字若其实进去了会打两遍；「总留一份」就是为这种情况准备的兜底
- 含 `Win` + 普通主键的组合会被系统抢先响应（截图、锁屏等）—— Windows 保留键的既定行为
- 剪贴板留一份只能保住**文本**：你原来复制的是图片或文件时无法还原（系统机制限制）
- 服务端结束帧被当普通帧丢弃、腾讯云丢掉官方句子序号、豆包"整段文本"兜底分支等**ASR 协议层问题**
  不在本版范围，保持原样（报告里已列明源码位置，下轮可处理）

## 🚀 核心能力（延续）

- 按住快捷键说话，松开即输入到光标处；边说边出字，识别被修正时自动回退重打
- 输入失败三级兜底：逐字注入 → 剪贴板粘贴 → 只放剪贴板并提示
- 三家流式 ASR 可切换：阿里云百炼（千问）/ 火山引擎（豆包）/ 腾讯云
- 托盘常驻、关窗即最小化；双击 exe 可唤起后台实例；开机自启可选（静默）
- 单文件 exe，免安装、无需运行库
````
