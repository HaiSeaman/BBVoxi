## 二、Release 正文（中文 · 整块复制）

```markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版解决一个让人抓狂的问题：**字有时候打不进去、或者打到了没点的地方**。
现在文字打不进去时不再"就此放弃"——会自动换一条通道，实在不行也一定把内容交到你手上。
单元测试 **82 → 98 条全部通过**。

## 🎁 本版新增

**1. 三级输入兜底：文字再也不会凭空消失（核心）**

有些程序不认"逐字模拟打字"这种输入方式（远程桌面、部分 Electron / Java / 老 MFC 程序），
以前遇到这种情况就结束了，你只能重新说一遍。现在按三级依次尝试：

| 级别 | 动作 | 什么时候用上 |
|---|---|---|
| ① 字符注入 | 逐字模拟打字 | 首选，不碰你的剪贴板 |
| ② 剪贴板粘贴 | 写入结果 → 自动按 `Ctrl+V` | 目标程序不认逐字注入时 |
| ③ 只放剪贴板 | 一个字都不输入，把结果放进剪贴板并提示 | 连粘贴也不安全时（窗口已切走、权限被拦） |

关键点：**`Ctrl+V` 和逐字注入在 Windows 里是两条完全不同的通道**，忽略前者的程序往往认后者 ——
所以"换一条通道再试"真的能救回很多场景。

**2. 不破坏你原来的剪贴板**

兜底粘贴后会**延迟约 300 毫秒自动还原你原来复制的内容**（还原前会核对剪贴板有没有被别人改写，改过就不动）。
另外新增一个开关「识别结果总留一份到剪贴板」（默认关）：打开后每次识别成功也留一份，
用来兜住那种"程序说注入成功了、字其实被悄悄丢掉"的情况。

**3. 设置窗新增「项目地址」按钮**

右下角一键用系统默认浏览器打开本项目主页。

## 🐞 本版修复（一轮全量代码审查）

- **【严重】文字被静默丢弃**：如果某一步注入失败过，收尾时程序会返回一个"假的成功"——
  结果既不进目标程序、也不进剪贴板，你刚说的话彻底消失。现在失败必须如实报错，
  并立刻把整段结果放进剪贴板
- **切走窗口再切回来，结果不再丢失**：以前"切出去看一眼再切回来"这一下就会把整段识别结果作废；
  现在切走只是**暂停**，切回来自动**恢复**输入
- **修好了"全局快捷键突然彻底失灵"**：在设置里进入改键状态后把窗口关掉，快捷键会永久失效且毫无提示。
  现在改键状态会随界面一起自动结束
- **剪贴板写入顺序修正**：以前写入失败时，你原来复制的内容可能已经被清空了
- 以及若干死代码清理、旧配置兼容、开机自启注册表句柄泄漏等小问题

## ⚠️ 升级与行为变化

直接用 `BBVoxi-1.3.exe` 覆盖旧版即可，**配置自动兼容，无需重填**。

两个新开关的默认值：
- 「输入被拒时用剪贴板粘贴兜底」= **开**（它只在逐字注入已经失败时才动剪贴板，而且先存后还）
- 「识别结果总留一份到剪贴板」= **关**（它会让你原来复制的东西一去不回，需要时请自行打开）

## ❗ 仍然存在的限制（说清楚，不夸大）

- 目标窗口以**管理员权限**运行时无法输入（Windows 系统限制），`Ctrl+V` 同样被拦 ——
  但**结果仍会复制到剪贴板**，粘到普通权限的窗口里就行
- **焦点不在任何输入框里**时，注入和粘贴都不会生效（两者都要靠焦点接收）——
  这种情况请打开「识别结果总留一份到剪贴板」，或直接去设置窗的「最近识别」里取
- 剪贴板兜底只能保住**文本**：你原来复制的是图片或文件时无法还原（系统机制限制，日志会写明）

## 🚀 核心能力（延续）

- 按住快捷键说话，松开即输入到光标处；边说边出字，识别被修正时自动回退重打
- 默认不碰剪贴板（逐字注入），你正在复制的内容不会被打断
- 三家流式 ASR 可切换：阿里云百炼（千问）/ 火山引擎（豆包）/ 腾讯云
- 托盘常驻、关窗即最小化；双击 exe 可唤起后台实例；开机自启可选
- 单文件 exe，免安装、无需运行库
