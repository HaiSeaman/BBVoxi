## 二、Release 正文（中文 · 整块复制）

````markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版是三个「你以为它在工作、其实它没工作」的问题的修复版，外加一轮全量审查的
**10 项加固**。单元测试 **139 → 156 条全部通过**。

## 🎁 本版修复（三件大事）

**1. 按住 `Ctrl + Win` 说话时，开始菜单不再突然弹出来**

- 根因在**按键顺序**：以前"凑齐组合的那一次按下才吞"，于是先按 Win、后按 Ctrl 时，
  Win 的按下被放给了系统——外壳记住"Win 按下过"，松开时必弹开始菜单抢走焦点，
  正在说话的你这一次结果就打不进目标程序（表现就是"突然断开 + 弹出开始界面"）
- 现在 **Win 的按下由本程序全程接管**，之后按你的真实意图补发：
  - 组合凑齐（先 Win 后 Ctrl、先 Ctrl 后 Win 都算）→ 全程吞掉，零补发
  - 只按了 Win → 补一整套 Win 按下+松开，**开始菜单照常可用**
  - `Win+E` 这类组合键 → 一次提交「Win↓ + 按键↓」，**系统快捷键照常生效**
- 以上全部经注入探针在真机实测验证

**2. 说过的话在剪贴板里找得到了（默认开启）**

- 以前两个缺陷叠在一起：兜底粘贴"先存后还"——写进剪贴板 300 毫秒后又被自己擦掉；
  而"字到底有没有打进目标程序"根本无法核实（实测 Chrome 连插入符都不报告）
- 现在「识别结果总留一份到剪贴板」**默认开启**（老配置自动升级），写入后还会**回读核对**；
  **会话中途失败**（网络超时、麦克风异常）时，已识别到的部分也会留一份
- 任何时候、任何地方 `Ctrl+V`，都能拿到你刚说的话

**3. "已复制到剪贴板"的提示不再弹出软件窗口**

- 删掉整条"会话请求显示窗口"的通道：提示改走**托盘悬浮文字**、设置窗里的提醒文字、
  以及日志——不再在你干活时把窗口顶到你脸上
- 窗口里那行"这份结果也留在了剪贴板"只在**回读核对通过**时才显示，
  复制失败会如实说"没能复制到剪贴板（原因）"，绝不让你对着空剪贴板干瞪眼

## 🔧 全量审查加固（10 项）

- **麦克风启动无超时**：设备被独占/驱动卡死时，会话线程被永久卡住、**所有热键失效**、
  界面停在"录音中"。现在 5 秒上限，超时如实报错
- **配置迁移每次启动都跑**：你自己把快捷键设成 Ctrl+反引号，下次启动会被悄悄改回默认值。
  现在迁移只在升级版本时执行
- **键盘钩子回调里做文件 I/O**：钩子被卡住会被 Windows **静默摘掉**（快捷键全失效且无声）。
  改为只记原子计数，日志由会话线程补记
- **钩子线程把 `GetMessageW` 的 -1（出错）当成"还有消息"**：空转刷 CPU 且钩子已失效无声
- **豆包响应解压无上限**：异常帧可把常驻进程内存吃光。现在 8 MB 上限
- **`AsrClient::close()` 是死函数**：承诺"让服务端看到正常关闭"却从没人调用。现在收尾时真正调用
- **单元测试会往你真实的日志文件里写**（205 条假现场，排查时会被带偏）：测试构建只写 stderr
- 删除与 `docs/界面截图.png` **字节完全相同**的重复素材；依赖精简（`rustls` 的 `logging` feature，
  `Cargo.lock` 里随之消失 `rustls → log` 这条依赖）
- 结构精简：音频共享句柄收成 `CaptureHandles`、`decide` 的 keyup 分支收成 `after_keyup()` 等

- 真剪贴板手测（写完 800 毫秒回读）**2 条通过**
- `cargo clippy` **未新增任何告警**

  见仓库 `docs/全量审查与修复报告.md`

## ⚠️ 升级与行为变化

退出正在运行的旧实例（托盘右键 → 退出），用 `BBVoxi-1.3.2.exe` 覆盖即可，**配置自动兼容**。

- **「识别结果总留一份到剪贴板」默认开启**（老配置自动升级）：代价是你原来复制的内容
  会被刚说的话顶掉——不想要就在设置里关掉，关掉后回到旧行为
- **"已复制到剪贴板"的提示不再弹窗**：去托盘悬浮文字或设置窗的「最近识别」看
- 其余设置（快捷键、服务商、自启）全部保持不变

## ❗ 仍然存在的限制（说清楚，不夸大）

- 目标窗口以**管理员权限**运行时无法输入（Windows 系统限制），`Ctrl+V` 同样被拦——
  但结果仍会留在剪贴板，粘到普通权限的窗口里就行
- 极少数程序会"**假装收下了**"我们的输入：Windows 没有通用接口能查证（实测 Chrome 连插入符
  都不报告），所以本版不做"检测到没进去就自动再粘一次"——字若其实进去了会打两遍；
  「总留一份」就是为这种情况准备的兜底
- 含 `Win` + 普通主键的组合会被系统抢先响应（截图、锁屏等）—— Windows 保留键的既定行为
- 剪贴板留一份只能保住**文本**：你原来复制的是图片或文件时无法还原（系统机制限制）

## 🚀 核心能力（延续）

- 按住快捷键说话，松开即输入到光标处；边说边出字，识别被修正时自动回退重打
- 三家流式 ASR 可切换：阿里云百炼（千问）/ 火山引擎（豆包）/ 腾讯云
- 托盘常驻、关窗即最小化；双击 exe 可唤起后台实例；开机自启可选（静默）
- 单文件 exe，免安装、无需运行库
````
