## 二、Release 正文（中文 · 整块复制）

````markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版做三件事：**把设置界面重做成页签式**（并支持三种主题）、**把千问升级到 3.1**、
**新增个人词典（热词）与识别语言**，并做了一轮**全仓库代码审查与清理**。
单元测试 **190 → 197 条全部通过**，`cargo clippy` **15 个告警清零**。

## 🗂️ 设置界面页签化

| 项 | 上一版 | 本版 |
|---|---|---|
| 布局 | 单张长卡片 + 说明全塞悬停气泡 | **顶部三页签**：语音服务 / 识别选项 / 通用 |
| 说明文字 | 鼠标停在小 `i` 上才展开 | **直接写在每行设置卡上**（一眼看懂） |
| 窗口宽度 | 520 | **580**（最小 520） |
| 主题 | 深浅两态 | **跟随系统 / 浅色 / 深色** |

- **三页签分栏**：一次性配置（服务商 / 凭据 / 个人词典）、识别行为（开关 + 识别语言）、
  常规（快捷键 / 开机自启 / 主题）各归各页，互不干扰
- **每行「标题 + 一句说明 + 右侧控件」**，开关行整行可点
- **主题点了立即生效并落盘**：写的是"上一次保存的配置 + 新主题"，
  **不是**编辑中的整份配置 —— 免得你填了一半还没保存的 API Key 被顺手存进文件
- 底部「最近识别」反馈条继续钉在窗口底，任何页签都看得见实时文字

## 🚀 千问升级 3.1

- 默认模型 **`qwen-audio-3.0` → `qwen-audio-3.1`**，老配置**自动迁移**
  （只升"从没动过"的旧默认值，你自己填过的模型名一个字都不动）
- **近场 VAD**（`near_meeting_16k`）：官方默认是"远场会议"（收全场声音），
  换成近场更贴合"对着麦克风说话"的输入法场景
- **中间结果显式开启**（官方默认关，不开就没有"边说边出字"）
- **修掉一个潜伏缺陷**：「口语顺滑」开关对千问一直是**摆设** —— 去语气词的参数从未传过，
  界面还写着"暂不支持"。现在真正接通

## 📖 个人词典（热词）

一行一个词，人名、品牌名、术语会被优先识别：

- **千问**：走"即时热词词表 + 上下文增强"**双通道**
- **豆包**：走请求级热词（官方要求是序列化后的 JSON 字符串格式）
- **腾讯云**：官方热词需在控制台预建词表，本程序未接 —— 界面**如实注明"此处不生效"**，不假装能用
- 没填词时一个字段都不多传，**行为与升级前一模一样**

## 🌏 识别语言

下拉可选：自动 / 中文 / 英语 / 粤语 / 日语 / 韩语 / 法语 / 德语 / 俄语 / 西班牙语

- **豆包**：适配官方 `language` 参数。该参数只在**整句模式**生效，所以选语言会自动切到整句端点
  （代价是出字晚一两秒，已在界面说明）
- **腾讯云**：按语言自动切换识别引擎；法语 / 德语 / 俄语 / 西班牙语**没有实时引擎**，
  会明确提示"换服务商或改回自动"，绝不拿中文引擎瞎认
- **千问**：模型自身多语种自动检测，保持"自动"即可
- 老配置不带这个字段会自动补"自动"，**行为与升级前完全一致**

## 🧹 全仓库代码审查与清理

- `cargo clippy` **15 个告警 → 0**（错误码数字分组歧义、手写 Default、多余 return、
  文档注释缩进、字段初始化方式等）
- 删掉一处**死代码**（布局 JSON 导出测试 —— 它的唯一消费者是已废弃的验收脚本，是条断头路）
  及它带出的死字段
- 清掉**无用文件**：3 个工具残留目录 + 10 个历史 UI 验收临时产物
- 逐个核实：23 个依赖、10 个 windows feature、所有公开常量**全部在用，无死依赖**
- 有意保留了 `Backend` 枚举几段"重复的 match 三家"—— 三家协议签名互不相同，
  抽 trait 只会加一层间接，违背本项目"简单能用"的原则

## 🧪 质量

- 单元测试 **190 → 197 条全部通过**

- 界面改动靠**无窗口布局探针**验收：跑真实 egui 布局代码、导出绘制指令来量尺寸 ——
  三页签每页内容总高 ≤ 600px、每页恰好 1 张卡片、**0 处文字越界**
- 单文件免安装，体积 **8.01 MB**

## ⚠️ 升级与行为变化

退出正在运行的旧实例（托盘右键 → 退出），用 `BBVoxi-1.4.0.exe` 覆盖即可。

**本版有一次性配置迁移**（配置版本 2 → 3）：老配置里"从没动过"的**千问旧默认模型 3.0**
会自动升级为 **3.1**（你自己填过的模型名原样保留）；其余设置全部原样保留。

新增的「个人词典」「识别语言」不填就是老样子，行为与升级前完全一致。

## ❗ 仍然存在的限制（说清楚，不夸大）

- 目标窗口以**管理员权限**运行时无法输入（Windows 系统限制），`Ctrl+V` 同样被拦——
  但结果仍会留在剪贴板，粘到普通权限的窗口里就行
- 极少数程序会"**假装收下了**"我们的输入：Windows 没有通用接口能查证，
  所以不做"检测到没进去就自动再粘一次"；「总留一份」就是为这种情况准备的兜底
- 含 `Win` + 普通主键的组合会被系统抢先响应（截图、锁屏等）—— Windows 保留键的既定行为
- 剪贴板留一份只能保住**文本**：你原来复制的是图片或文件时无法还原（系统机制限制）
- **腾讯云没有法语 / 德语 / 俄语 / 西班牙语的实时识别引擎**，选到会提示换服务商
- **个人词典对腾讯云不生效**（腾讯热词要在控制台预建词表）
- **豆包选语言会切到整句模式**，出字比"自动"晚一两秒

## 🚀 核心能力（延续）

- 按住快捷键说话，松开即输入到光标处；边说边出字，识别被修正时自动回退重打
- 输入失败三级兜底：逐字注入 → 剪贴板粘贴 → 只放剪贴板并提示
- 三家流式 ASR 可切换：阿里云百炼（千问 3.1）/ 火山引擎（豆包）/ 腾讯云
- 托盘常驻、关窗即最小化；双击 exe 可唤起后台实例；开机自启可选（静默）
- 单文件 exe，免安装、无需运行库
````
