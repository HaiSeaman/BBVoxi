## 二、Release 正文（中文 · 整块复制）

````markdown
**Windows 按住说话的语音输入法：按住快捷键说话，松开即把字打到光标处。**

本版做三件事：**加了一键自动更新**、**录音可以选麦克风**、**做了两轮全量代码审查修掉约 50 项问题**
（其中会丢数据 / 丢密钥 / 麦克风停不下来的硬伤 8 条）。
单元测试 **197 → 239 条全部通过**，真机验证了"查版本 → 下载 8.4 MB → 核对指纹"整条路。

## 🔄 一键自动更新（新功能）

设置窗底部多了「检查更新」按钮，点一下：

1. 后台去 GitHub 问最新版本（**平时一个字节都不发**，只在你点按钮时联网）
2. 有新版本 → 弹窗「发现新版本 vX.Y.Z」+ 更新说明，**你确认了才开始下载**
3. 下载时底部实时显示"正在下载 42%（3.5/8.0 MB）"
4. 下载完**自动核对 SHA-256 指纹**（GitHub 官方公布的那个）—— 对不上立刻删掉并报错，绝不装来路不明的内容
5. 装好后弹窗「更新已装好」+【稍后】【立刻重启】，重启就是新版本

- **国内网络专门优化**：走 Windows 系统代理（实测比直连**快 10 倍**：663 KB/s vs 68 KB/s）；
  代理软件关了但系统设置还开着时，自动退回直连
- **失败有退路**：网络不通 / 校验不过 / 目录写不了，都用大白话说清原因，并给一个「手动下载」按钮直接打开发布页
- **两道保护**：正在录音时不许重启（否则这句话白说）；有改动没保存时不许重启（否则改动会丢）
- **起不来就退回**：重启后会先确认新版本进程真的活着，才让旧进程退出 —— 万一新版本起不来，你手里那个还能用

> ⚠️ 说明：**自动更新从本版开始才有**，所以 1.4.0 及更早的用户这次要**手动下载覆盖**；
> 从 1.4.1 起，以后升级就都是一键的了。

## 🎤 录音麦克风可选（新功能）

「通用」页新增「麦克风」下拉栏：

- 列出本机**所有**能录音的设备（默认一项是「系统默认」，跟随 Windows）
- **显示的是 Windows 里那个好认的名字**（比如 `麦克风 (BY-CM1)`），
  存的却是**设备唯一编号** —— 两台同型号麦克风名字一模一样，只有编号分得开
- 选中的设备**不在线时自动回退系统默认设备**（不会因为选错就录不出声），那一行会写明怎么恢复
- 「刷新」按钮：插上 / 拔掉设备后点一下就更新列表；名字太长会被截断，**鼠标停上去能看全**

## 🛡️ 两轮全量代码审查（约 50 项修复）

按「功能正确性」和「代码规范」两条线分开审，6 路 + 5 路只读审查员按模块深挖，
**每条结论都经维护者逐行复核**后才动手。修掉的重点：

- **不再可能丢密钥**：配置文件读不出来时（可能只是被临时占用），会先把原文件另存成 `config.json.bad` 再回退，
  以前那种"之后随手一点就把真配置覆盖成空配置"的路彻底堵死
- **录音途中改快捷键/保存设置，麦克风不会再停不下来**（以前只清状态、不发停止指令，会话永远等不到"结束"）
- **改键时不会再卡住 Win 键**（以前捕捉期间无条件吞掉 Win 的松开，之后敲字母就会弹出开始菜单/资源管理器）
- **点「立刻重启」不再无声丢掉没保存的改动**（现在会拦一句"先点保存"）
- **音频回调线程里不再写日志**（磁盘一忙就会卡住回调——那就是丢音）
- **服务端掐断连接不再被误报成"没有识别到内容，请靠近麦克风再说一次"**（千问/腾讯现在如实报关闭码和原因）
- 「不保存」现在**真的**把改动丢掉（以前下次打开设置窗它们又回来了，再点保存就一起写进文件）
- 更新相关的：版本号比较支持任意段数（`1.5.0.1` 不会再被当成 `1.5.0`）、下载临时文件名会先清洗、
  更新线程异常退出不会让按钮永远灰着、临时文件不会残留
- 界面：底栏按钮重排后版本号不会再被挤出窗口；新增一条"面板不许被长文字撑宽"的排版守卫测试

另有 8 项**需要真帧或真机证据**的问题如实保留（腾讯云句序、豆包"定稿翻回"行为、千问句号单调性、
服务端关闭码语义、开机自启在"快速启动"机器上的判定等），已在审查报告里逐条写明原因，不猜着改。

## 📦 升级方式

- **1.4.0 及更早**：下载本页的 `BBVoxi-1.4.1.exe`，覆盖旧的 exe 即可 —— 配置自动兼容，**本版无需迁移**
- **从本版起**：以后直接点设置窗底部的「检查更新」

## ℹ️ 其他

- 单文件免安装：`BBVoxi-1.4.1.exe`，**8.37 MB**，Windows 10 1809+ / 11（x86_64），普通用户权限
- 三家语音服务（千问 / 豆包 / 腾讯云）与音频规格无变化
- 程序要放在**自己能写的目录**里（放 `C:\Program Files` 会被系统拒绝替换，程序会在下载前就提示你）
- exe **没有代码签名证书**，更新后第一次运行 Windows 可能提示"未知发布者"（未签名软件的通病）

**校验下载完整性：**

```powershell
Get-FileHash .\BBVoxi-1.4.1.exe -Algorithm SHA256
```
````
